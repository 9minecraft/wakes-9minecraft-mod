# Wakes — Leave Realistic Wave Trails Behind Your Boat

Wakes 9minecraft Mod adds realistic waves and ripples behind anything moving through water. Whenever you ride a boat, swim across an ocean, or watch a mob wade through a river, soft foam and water trails appear right behind them. These trails spread out across the surface and fade away naturally. The visual effect works completely on your client, meaning you can join any multiplayer server without needing the server to install it.

## What this build is

An unofficial rebuild of **Goby56**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
